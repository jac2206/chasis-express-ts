# Skill: Express + Node + TypeScript

Usa este skill al exponer capacidades HTTP. Crea rutas v1 bajo el prefijo del servidor, aplica `express.json()`, validación Zod, autenticación y scopes antes del handler. Mantén controladores sin lógica de negocio y deja que el middleware global gestione `DomainException`. Mantén TypeScript estricto y evita `any`.
