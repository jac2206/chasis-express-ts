# Plantilla de solicitud SDD

```md
## Contexto
[módulo y actor]

## Objetivo
[resultado de negocio observable]

## Reglas
- [regla e identificador de error si falla]

## Contrato HTTP
[método, ruta, autenticación, scope, request, response y estados]

## Criterios de aceptación
- [escenario Given/When/Then]

## Fuera de alcance
- [límites explícitos]
```

No implementar una regla relevante que no aparezca en el contexto o que no haya sido confirmada.
